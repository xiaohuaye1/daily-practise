# daily-practise

记录我学习 C、C++、Python，以及数据结构与算法的练习代码和思考。

A little progress every day.

## 仓库目录

| 目录 | 内容 |
| --- | --- |
| `练手题目(基础)/` | C 语言基础练习：指针、字符串、结构体、动态内存、递归等 |
| `C++/基础/` | C++ 基础练习：引用、类与对象、构造与析构、友元、运算符重载等 |
| `python/` | Python 基础语法与算法小练习 |
| `数据结构与算法/` | 链表、栈、队列、树，以及图的遍历、最短路径、最小生成树等 |
| `算法竞赛题目.c/` | BFS、二分查找、动态规划等题目练习 |

## 部分练习

- 链表操作：练习插入、删除、反转和快慢指针。
- 连通块查询：通过 BFS 标记连通块，缓存大小以减少重复搜索。
- 二分答案——砍树：根据获得的木材总量，寻找满足要求的最大切割高度。
- 动态规划——马走日：在有障碍和受攻击位置的棋盘上统计路径数量。
- C++ 赋值运算符重载：练习深拷贝与动态内存管理。
